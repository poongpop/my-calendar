# 내 캘린더 (GitHub 동기화 개인 캘린더)

맥북과 안드로이드에서 같이 쓰는 개인 캘린더 PWA입니다.
앱 화면은 GitHub Pages에서 열리고, 일정 데이터는 **비공개 저장소**의 `events.json`에 저장됩니다.

## 구조

| 저장소 | 공개 여부 | 내용 |
|---|---|---|
| `my-calendar` (앱) | 공개도 괜찮음 | 이 폴더의 파일들(화면 코드만 있고 데이터는 없음) |
| `my-calendar-data` (데이터) | **반드시 Private** | `events.json` (앱이 자동 생성) |

앱 주소를 다른 사람이 알아도 토큰이 없으면 빈 화면만 보입니다.

## 설치 (한 번만 하면 됨)

### 1. 데이터 저장소 만들기
GitHub → New repository → 이름 `my-calendar-data` → **Private** 선택 → "Add a README file" 체크 → Create.

### 2. 앱 저장소 만들고 Pages 켜기
1. New repository → 이름 `my-calendar` → Create.
2. "uploading an existing file"을 눌러 이 폴더의 파일 6개(index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, README.md)를 업로드하고 Commit.
3. Settings → Pages → Source: **Deploy from a branch**, Branch: `main` / `(root)` → Save.
4. 1~2분 뒤 `https://<사용자명>.github.io/my-calendar/` 에서 앱이 열립니다.

> 무료 계정은 Pages를 쓰려면 앱 저장소가 Public이어야 합니다. GitHub Pro(학생은 GitHub Student Developer Pack으로 무료)라면 앱 저장소도 Private으로 둘 수 있습니다. 단, 그래도 Pages 주소 자체는 누구나 접속할 수 있습니다.
> **데이터 파일을 앱 저장소에 넣지 마세요.** Pages가 그 파일까지 공개 주소로 내보냅니다.

### 3. 기기별 토큰 만들기 (맥용 1개, 폰용 1개 권장)
GitHub → 프로필 사진 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token

- Token name: `calendar-mac` (폰용은 `calendar-phone`)
- Expiration: 원하는 기간(만료되면 새로 발급해서 앱 설정에 다시 입력)
- Repository access: **Only select repositories** → `my-calendar-data` 하나만
- Permissions → Repository permissions → **Contents: Read and write** (Metadata: Read-only는 자동)
- Generate → `github_pat_...`로 시작하는 토큰 복사 (이 화면을 벗어나면 다시 볼 수 없음)

폰용 토큰은 폰 브라우저에서 GitHub에 로그인해서 직접 발급하면 복사·붙여넣기가 편합니다.

### 4. 앱에 연결
앱을 열면 설정 창이 뜹니다(나중에 ⚙︎ 버튼으로도 열 수 있음).
- GitHub 사용자명 / 데이터 저장소(`my-calendar-data`) / 토큰 입력 → **연결 테스트** → 저장
- 저장소가 Public이면 경고가 뜨고 저장되지 않습니다.

### 5. 앱으로 설치
- **안드로이드 (크롬)**: 앱 주소 열기 → ⋮ 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
- **맥 (크롬)**: 주소창 오른쪽의 설치 아이콘 클릭
- **맥 (사파리, Sonoma 이상)**: 메뉴 파일 → "Dock에 추가"

## 사용법
- **화면 전환**: 좌우로 스와이프(폰) / 트랙패드 두 손가락 좌우 스와이프(맥) / 상단 '일정·메모' 탭 / 단축키 `m`
- **달 이동**: 달력을 위아래로 스와이프(폰) / ‹ › 버튼 / PageUp·PageDown(맥)
- **날짜 이동(맥)**: 방향키 ← → 하루, ↑ ↓ 일주일
- **여러 날 일정**: 달력에서 시작일~종료일이 하나의 막대로 이어져 보임(주가 바뀌면 다음 줄에서 이어짐). 한 칸에 4개 이상이면 '+n' 표시
- **일정+투두 한 패널**: 날짜를 누르면 패널 하나에 시간대 칸이 나옴. 그날의 모든 일정은 항상 '하루 할 일' 맨 위에 색 막대로 표시(종일 먼저, 그다음 시간순, 누르면 편집). 시간 있는 일정은 이와 별개로 그 시간대 칸 맨 위에도 투두로 자동 등록(시각 표시, **누르면 일정 편집 창**, 일정을 고치면 따라감, 일정·시각을 지우면 같이 삭제)
- **투두**: 하루 할 일 / 06–12 / 12–15 / 15–18 / 18–21 / 21–24 / 새벽(0–6시) 칸
  - 각 칸 아래 빈 줄을 눌러 적고 Enter (입력칸이 유지되어 연속 입력 가능)
  - 왼쪽 **✓ = 성공(노란 형광펜)**, **◐ = 진행했지만 못 끝냄(주황 밑줄)**, **✕ = 실패(빨간 글씨)**. 켜진 버튼을 한 번 더 누르면 해제.
  - 끄는 동안 새벽 칸 아래에 '다음 날로 옮기기' 칸이 나타남 → 놓으면 다음 날 06–12로 이동 글자를 누르면 수정(내용을 다 지우면 삭제), × 로 삭제
  - 시간대 칸 오른쪽 숫자는 '성공/전체', 진행·실패가 있으면 '진행 n', '실패 n'도 표시
  - **옮기기**: 맥은 끌어다 놓기, 폰은 꾹 눌러 집은 뒤 이동. 다른 시간대 칸 / 같은 칸 안 순서 / 달력의 다른 날짜(시간대 유지)에 놓을 수 있음.
    끄는 중에 달력 날짜 위에 잠깐 머물면 그 날짜의 투두가 열려서 원하는 시간대에 바로 놓을 수 있음
- **주차 표**: 달력 왼쪽 '1주차, 2주차…'를 누르면 그 주 아래로 요일 × 시간대 표가 펼쳐짐(다시 누르면 접힘).
  표 안에서도 추가·성공/실패 표시·수정·끌어서 옮기기 모두 가능. 요일 머리글을 누르면 그 날짜 선택. 주차 칸의 숫자는 그 주에 남은 투두 수.
  폰에서는 표를 좌우로 밀어서 봄
  - 달력 칸 오른쪽 위 숫자: 맥은 '체크한 것(성공+실패)/전체', 폰은 남은 개수(다 끝나면 ✓)
- **날짜·시각 초기화**: 일정 창의 각 칸 옆 × 버튼. 시작일은 창을 열 때의 날짜로, 종료일·시각은 빈 값으로 되돌림
- **일정 창 닫기**: 팝업 바깥을 더블클릭(폰은 두 번 탭)하면 저장하지 않고 취소
- **폴더**: 일정·메모 화면 위의 칩 줄에서 `+ 폴더`로 생성. 칩을 누르면 그 폴더만 보기, 선택된 칩을 한 번 더 누르면(맥은 우클릭도 가능) 이름 변경·삭제.
  폴더를 삭제해도 안의 항목은 지워지지 않고 '미분류'로 이동합니다. 메모의 '전체' 보기는 폴더별로 묶여서 표시됩니다.
  폴더를 선택한 상태에서 새 일정·메모를 만들면 그 폴더에 들어갑니다.
- 날짜 클릭 → 오른쪽(폰은 아래)에 그날 일정 표시 / 더블클릭 → 바로 새 일정
- `+ 일정` (폰은 오른쪽 아래 + 버튼)으로 추가, 일정을 누르면 수정·삭제
- 여러 날 일정: 종료일 입력 / 종일 일정: "종일" 체크
- 맥 단축키: `t` 오늘, `n` 새 일정, `m` 일정·메모 전환

## 메모장
- 좌우 스와이프나 상단 '메모' 탭(맥 단축키 `m`)으로 메모 화면 전환
- 첫 줄이 제목이 되고, 입력 중 1.5초마다 자동 저장됩니다. Esc나 바깥을 눌러 닫아도 저장됩니다.
- 내용을 모두 지우고 닫으면 메모가 삭제됩니다. 상단 검색창으로 내용 검색 가능
- 메모는 일정과 같은 `events.json` 파일의 `notes` 항목에 저장됩니다. 같은 메모를 두 기기에서 동시에 고치면 나중에 저장한 쪽이 남습니다.

### 메모 마크다운
- 메모를 열면 서식이 적용된 **보기 화면**으로 열림 → 글을 누르거나 오른쪽 위 '편집'을 누르면 원문 편집, '보기'로 다시 확인
- 지원 문법: `# 제목`(##, ### 까지), `**굵게**`, `*기울임*`, `~~취소선~~`, `==형광펜==`, `- 목록`, `1. 번호 목록`,
  `- [ ] 체크박스`(보기 화면에서 눌러서 체크/해제), `> 인용`, `` `코드` ``, ```` ``` ```` 코드 블록, `---` 구분선, `[글자](https://주소)` 링크(주소만 써도 링크)
- **서식 버튼(편집 화면 위)**: B 굵게 · I 기울임 · S 취소선 · 형광펜 · H1/H2 제목 · 목록 · 번호 · 체크 · 인용 · 코드 · 링크 · 구분선
  - 글을 드래그해서 선택한 뒤 누르면 그 부분에 적용(다시 누르면 해제). 목록·제목·체크·인용은 선택한 여러 줄에 한꺼번에 적용
  - 아무것도 선택하지 않고 누르면 기호가 먼저 들어가고 그 안에서 바로 쓰기
  - 목록 줄에서 Enter → 다음 줄에 `- `, `2. `, `- [ ] ` 자동으로 이어짐. 빈 항목에서 Enter → 목록 끝
  - 맥 단축키: ⌘B 굵게, ⌘I 기울임, ⌘K 링크, ⌘E 코드, ⌘⇧X 취소선, ⌘⇧H 형광펜 (⌘Z 실행 취소 가능)
- 메모 목록 카드에는 기호를 뺀 글자만 표시

## 동기화 방식
- 일정을 저장하면 약 1초 뒤 자동으로 GitHub에 커밋됩니다.
- 앱을 다시 열 때, 화면에 돌아올 때, 열려 있는 동안 1분마다 자동으로 동기화합니다. ⟳ 버튼으로 즉시 동기화할 수 있습니다.
- 오프라인에서 수정한 내용은 기기에 보관했다가 연결되면 올립니다.
- 두 기기에서 동시에 수정해도 일정별로 더 최근에 수정한 쪽을 기준으로 합쳐지므로 데이터가 사라지지 않습니다.
- `my-calendar-data` 저장소의 커밋 기록이 그대로 변경 이력(백업)이 됩니다.

## 보안 수칙
- 기기를 잃어버리면 GitHub → Fine-grained tokens에서 **그 기기의 토큰만 삭제**하면 즉시 접근이 차단됩니다.
- 공용 컴퓨터에서 썼다면 ⚙︎ → "이 기기 초기화"로 토큰과 캐시를 지우세요.
- 토큰은 데이터 저장소 하나에만 권한이 있으므로, 유출되더라도 다른 저장소나 계정에는 영향이 없습니다.

## 앱 수정하기
`index.html`을 고쳐서 앱 저장소에 다시 올리면 됩니다. 앱이 바로 바뀌지 않으면 한 번 새로고침하세요.
